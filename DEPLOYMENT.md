# PromptRouter - Deployment Guide

## 🚀 Quick Start Deployment

### Prerequisites
- Railway account with paid plan
- Vercel account
- Clerk account (for authentication)

---

## Backend Deployment (Railway)

### 1. Create Railway Project

```bash
cd backend
railway login
railway init
```

### 2. Add PostgreSQL Database

In Railway dashboard:
1. Click "New" → "Database" → "PostgreSQL"
2. Railway will automatically set `DATABASE_URL` environment variable

### 3. Add Redis (Optional but Recommended)

In Railway dashboard:
1. Click "New" → "Database" → "Redis"
2. Railway will automatically set `REDIS_URL` environment variable

### 4. Set Environment Variables

In Railway dashboard, add these variables:

```
# Auto-generated by Railway
DATABASE_URL=postgresql://...
REDIS_URL=redis://...
PORT=8000

# Add manually
ENVIRONMENT=production
API_SECRET_KEY=<generate-strong-key>
ENCRYPTION_KEY=<generate-32-char-key>

# CORS - Add your Vercel domain after deployment
ALLOWED_ORIGINS=https://your-app.vercel.app
```

Generate secure keys:
```bash
# API Secret Key
python -c "import secrets; print(secrets.token_urlsafe(32))"

# Encryption Key (must be 32 characters)
python -c "import secrets; print(secrets.token_urlsafe(24))"
```

### 5. Deploy

```bash
railway up
```

Or connect your GitHub repo for automatic deployments.

Your backend will be available at: `https://your-project.up.railway.app`

## Frontend Deployment (Vercel)

### 1. Configure Clerk

1. Go to [clerk.com](https://clerk.com)
2. Create a new application
3. Copy your publishable and secret keys

### 2. Set Environment Variables

In your Vercel project settings, add:

```
NEXT_PUBLIC_API_URL=https://your-backend.up.railway.app
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=pk_live_xxxxx
CLERK_SECRET_KEY=sk_live_xxxxx
```

### 3. Deploy to Vercel

```bash
cd frontend
npm install -g vercel
vercel login
vercel
```

Or connect your GitHub repo in Vercel dashboard.

### 4. Update CORS in Backend

After Vercel deployment, update Railway backend environment:

```
ALLOWED_ORIGINS=https://your-app.vercel.app,https://your-app-*.vercel.app
```

Redeploy backend for changes to take effect.

## Database Migrations

Railway PostgreSQL will auto-create tables on first startup via the `lifespan` function in `main.py`.

For manual migrations:

```bash
# Connect to Railway DB
railway run bash
python -c "from app.core.database import engine, Base; import asyncio; asyncio.run(engine.begin()); print('Tables created')"
```

## Troubleshooting

### Backend won't start
- Check Railway logs for errors
- Verify `DATABASE_URL` is set
- Ensure `PORT` environment variable is set

### CORS errors
- Verify `ALLOWED_ORIGINS` includes your Vercel domain
- Check Vercel deployment URL matches exactly

### Database connection errors
- Railway PostgreSQL may take 1-2 minutes to provision
- Check `DATABASE_URL` format: `postgresql://user:pass@host:port/db`

### Frontend can't reach backend
- Verify `NEXT_PUBLIC_API_URL` is set correctly
- Check backend `/health` endpoint is accessible
- Ensure no trailing slashes in URL
